# 计算机视觉实验12：Sinusoidal位置编码与RoPE实现及对比
## 项目简介
本项目基于PyTorch实现**传统正弦位置编码(Sinusoidal PE)**与**RoPE旋转位置编码**，完成二维向量旋转、高维RoPE编码、输入方式对比、相对位置数值验证，对比两种位置编码的原理、优劣与适用场景，配套完整实验代码与结果可视化。

## 实验内容（对应课程作业）
1. 实现标准Sinusoidal正弦位置编码；
2. 实现基础二维向量旋转函数；
3. 实现高维RoPE旋转位置编码；
4. 对比 E+pos（加法融合）与 RoPE（旋转融合）的输入方式；
5. 数值实验验证RoPE「相对位置不变」核心性质；
6. 理论分析RoPE相较于传统位置编码的优势。
