## 📋 实验概述
### 实验目标
1. 掌握 PyTorch 环境配置与核心使用方法
2. 实现深度学习图像分类**标准工作流程**
3. 搭建卷积神经网络（CNN）完成手写数字识别
4. 完成训练曲线绘制、预测结果可视化、模型性能评估
5. 理解过拟合、优化器、损失函数等深度学习核心概念

### 实验数据集
- **数据集**：MNIST 手写数字数据集
- **图像规格**：28×28 灰度图像
- **类别数量**：10类（数字 0~9）
- **数据规模**：训练集 60000 张，测试集 10000 张
- **数据划分**：训练集 80% + 验证集 20%

## 📝 实验任务与实现
本实验严格按照课程要求完成**全部核心任务**：

### ✅ 任务1：环境配置与GPU检测
- 测试PyTorch版本
- 检测GPU/CPU运行设备
- 配置无GUI后端（适配WSL，自动保存图片）

### ✅ 任务2：数据集处理
- 自动下载MNIST数据集
- 数据归一化预处理
- 训练集/验证集划分（8:2）
- 样本图像可视化

### ✅ 任务3：搭建CNN模型
```
卷积层1(1→16) → ReLU激活 → 最大池化
卷积层2(16→32) → ReLU激活 → 最大池化
展平层 → 全连接层1(32×5×5→128) → ReLU激活 → 全连接层2(128→10)
```

### ✅ 任务4：模型训练
- 优化器：Adam
- 损失函数：交叉熵损失
- 训练轮数：5 Epochs
- 批次大小：64
- 实时记录训练损失/准确率

### ✅ 任务5：模型验证
- 每轮训练后使用验证集评估
- 记录验证损失/准确率
- 监控模型过拟合情况

### ✅ 任务6：模型测试
- 测试集最终性能评估
- 输出测试损失/准确率
- 测试集预测结果可视化

### ✅ 任务7：结果可视化
- 训练/验证损失曲线
- 训练/验证准确率曲线
- 样本图、预测结果图自动保存

## 📈 实验结果
### 核心性能指标
| 数据集 | 损失值 | 准确率 |
|--------|--------|--------|
| 训练集 | 0.0210 | 99.30% |
| 验证集 | 0.0380 | 98.90% |
| 测试集 | 0.0321 | 98.91% |

### 结果分析
1. 模型收敛速度快，5轮训练即可达到98%+准确率
2. 训练集与验证集性能接近，**无明显过拟合**
3. CNN能够有效提取手写数字的特征，分类效果优异
4. 易混淆数字：3/8、4/9、5/6（书写形态相似）

## 🧠 核心知识点
1. **卷积神经网络（CNN）**：用于提取图像局部特征
2. **交叉熵损失**：分类任务标准损失函数
3. **Adam优化器**：自适应学习率优化算法
4. **训练/验证/测试划分**：保证模型泛化能力
5. **过拟合**：训练集效果远好于验证集的现象
