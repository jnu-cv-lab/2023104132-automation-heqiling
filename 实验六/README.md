# 计算机视觉实验 - 任务1：ORB 特征点检测

## 任务概述
本任务为图像局部特征实验的**第一步**，使用 **ORB 算法** 对模板图像和场景图像进行特征点检测，提取图像中的角点、纹理边缘等显著特征点，并可视化展示检测结果。

## 实验环境
- 操作系统：WSL Ubuntu 24.04
- 编程语言：Python 3
- 依赖库：OpenCV、NumPy
- 开发工具：VSCode

## 输入图像
将以下两张图片放置在代码同一级目录：
1. `box.png` - 待检测的模板物体图像
2. `box_in_scene.png` - 包含模板物体的场景图像

## 运行方法
1. 激活虚拟环境（如已配置）
   ```bash
   source /home/hql/cv-course/.venv-dl/bin/activate
   ```
2. 进入代码目录
   ```bash
   cd /home/hql/cv-course/experiment6/（1）/
   ```
3. 运行代码（仅执行任务一特征检测）
   ```bash
   python3 orb_feature_matching.py
   ```

## 输出结果
程序运行后自动生成两张可视化图片：
1. `task1_orb_kp_temp_1000.jpg` - 模板图像 ORB 特征点检测结果
2. `task1_orb_kp_scene_1000.jpg` - 场景图像 ORB 特征点检测结果

## 核心功能说明
1. **ORB 特征检测器**
   - 基于 FAST 角点检测 + BRIEF 二进制描述子
   - 具备旋转不变性、尺度不变性
2. **特征点分布**
   - 集中在图像角点、纹理丰富区域
   - 平坦区域无特征点生成
3. **可视化效果**
   - 绿色圆点标记检测到的特征点
   - 包含特征点的方向、尺度信息

## 终端输出信息
- 模板图像检测到的特征点数量
- 场景图像检测到的特征点数量
- ORB 描述子维度（256bit）
