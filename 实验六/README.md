# 计算机视觉实验：局部特征检测与图像匹配
完整实现 ORB 特征检测、特征匹配、RANSAC 误匹配剔除、目标定位、参数对比及 SIFT 对比实验

## 实验概述
本实验基于 OpenCV 实现图像局部特征的全流程处理，完成**6项核心任务 + 1项选做任务**，验证局部特征在目标检测、图像匹配中的应用：
1. ORB 特征点检测
2. ORB 特征暴力匹配
3. RANSAC 算法剔除错误匹配
4. 基于单应矩阵的目标定位
5. 实验结果分析
6. 特征点数量参数对比实验
7. 选做：SIFT 特征匹配与 ORB 对比

## 实验任务详情
### 任务1：ORB 特征检测
使用 ORB 算法检测图像角点、纹理区域特征点，可视化展示关键点分布，输出特征点数量与描述子维度。

### 任务2：ORB 特征匹配
采用暴力匹配器（汉明距离）对特征描述子进行匹配，输出最优匹配对。

### 任务3：RANSAC 误匹配剔除
通过随机采样一致性算法，剔除几何不一致的错误匹配，输出单应矩阵、内点数量与内点比例。

### 任务4：目标定位
利用单应矩阵将模板角点投影到场景图，绘制边框实现精准目标定位。

### 任务6：参数对比实验
自动测试 `500/1000/2000` 三组特征点数量，对比匹配效果、内点比例与定位成功率。

### 选做任务：SIFT 特征匹配
实现 SIFT 算法检测与匹配，对比 ORB 与 SIFT 在精度、速度上的差异。

## 核心算法说明
1. **ORB**：二进制特征，速度快，具备旋转/尺度不变性，适用于实时匹配
2. **RANSAC**：基于几何一致性剔除误匹配，提升匹配鲁棒性
3. **单应矩阵**：描述平面物体的投影变换关系，用于目标定位
